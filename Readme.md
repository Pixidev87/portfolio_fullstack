# Fullstack Portfolio Website

## 🇭🇺 Magyar bemutatás

Ez a projekt a személyes portfólió weboldalam.

A backend Laravel 12 alapú REST API, amely clean architecture elvek szerint épül fel (Controller → Service → Repository rétegezéssel).

A frontend React és Bootstrap 5 használatával készül, különálló alkalmazásként.

A projekt célja a modern full-stack fejlesztési szemlélet és a tiszta, strukturált kód bemutatása.


---

## 🇬🇧 English Description

This project is my personal portfolio website.

The backend is built with Laravel 12 as a REST API following clean architecture principles (Controller → Service → Repository layers).

The frontend is built as a separate React application styled with Bootstrap 5.

The goal of this project is to demonstrate modern full-stack development practices and clean, maintainable code structure.
